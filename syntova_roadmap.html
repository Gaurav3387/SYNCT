Phase 1: Foundation & Cloud Transition

Month 1 - Advanced SQL + Oracle Re-entry

Objective: Rebuild existing database expertise and prepare for technical SQL interviews.

Core Syllabus

  • Advanced filtering, sorting, aggregates
  • INNER, LEFT, RIGHT, FULL, Self & Cross Joins
  • Correlated subqueries & CTEs
  • Window functions (ROW_NUMBER, RANK, DENSE_RANK)
  • LEAD, LAG, Running totals, Moving averages

 

  • PL/SQL blocks, Cursors, Procedures, Functions
  • Triggers, Exception handling, Dynamic SQL
  • Indexes, Query optimisation, Normalisation
  • Transactions, COMMIT/ROLLBACK, Locking

Month 1 Deliverable: Banking Transaction Management DB

Build schema: Customer, Account, Transaction, Loan, Branch. Develop PL/SQL procedures, triggers, and daily reconciliation reports.

Month 2 - Python for Data Engineering

Objective: Move from SQL-only development to Python integration and data processing.

Core Syllabus

  • Python variables, data types, operators, loops
  • Lists, Tuples, Sets, Dictionaries, Strings
  • OOP: Classes, Objects, Inheritance
  • Lambda, map/filter, List comprehension
  • NumPy & Pandas for data manipulation

 

  • Handling CSV, JSON, Excel, Parquet
  • Data validation & cleaning techniques
  • SQLAlchemy & SQL execution from Python
  • Virtual environments, pip, logging
  • Git, GitHub, Commits, Pull requests

Month 2 Deliverable: Python Banking Data System

Input: CSV → Python → Transformation → Validation → Oracle/MySQL. Output clean dataset & reconciliation reports.

Month 3 - AWS Cloud Fundamentals

Objective: Build a strong comfort level with cloud infrastructure before advancing to ETL services.

Phase 2: Data Engineering & Certification

Month 4 - Core Data Engineering

Objective: Master data pipelines, modern data warehousing, and AWS analytics services.

Core Syllabus

  • ETL vs ELT architectures, Batch vs Incremental
  • CDC concepts, Delta loads, Error handling
  • AWS Glue Data Catalog, Crawlers, Jobs
  • Amazon Athena & S3 Data Lakes

 

  • Data Warehouse OLTP vs OLAP
  • Star/Snowflake schemas, Fact & Dimension tables
  • Slowly Changing Dimensions, Partitioning
  • Apache Airflow: DAGs, Tasks, Scheduling

Month 4 Deliverable: Banking Data Warehouse

Source (Oracle/CSV) → S3 Data Lake → AWS Glue Transformation → Redshift Analytics tables. Candidate must explain architecture blind.

Month 5 - PySpark & Advanced Engineering

Objective: Scale processing with PySpark and prepare for the official AWS examination.

Core Syllabus

  • Spark architecture: Driver, Executors, RDDs
  • DataFrames, Transformations vs Actions
  • PySpark joins, aggregations, Window functions
  • Partitioning, Caching, Performance tuning

 

  • Data quality, Schema validation, Null handling
  • Error tables, Retry mechanisms, Data lineage
  • AWS Optimisation: Glue, Redshift, S3, Costs
  • Begin AWS DEA-C01 Certification Prep

Month 5 Deliverable: End-to-End Financial Pipeline

Integrate Python, SQL, PySpark, S3, Glue, Redshift, and Airflow with data quality checks, logging, and CloudWatch monitoring.

Month 6 - Certification + Placement Bootcamp

Objective: Convert skills and projects into a polished resume, pass the exam, and secure employment.

Core Syllabus

  • Resume Building & LinkedIn Optimization
  • Mock Technical Interviews
  • AWS DEA-C01 Final Practice Exams
